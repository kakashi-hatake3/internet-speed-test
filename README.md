# Замерятель скорости интернет-соединения (Internet Speed Test CLI)

Консольная утилита для измерения скорости интернет-соединения путем последовательных HTTP/HTTPS-запросов к целевому ресурсу (тяжелой картинке, тестовому бинарному файлу и т.д.).

---

## Требования

* **Python 3.10+** (проверено на Python 3.12).
* Внешние зависимости для запуска **не требуются** (используется стандартная библиотека Python: `urllib`, `argparse`, `dataclasses`).

---

## Использование

### 1. Быстрый запуск

Запуск без аргументов использует по умолчанию тестовый эндпоинт Cloudflare (10 МБ):
```bash
python3 main.py
```

Или с явным указанием URL (например, файл 10 МБ или 25 МБ):
```bash
python3 main.py "https://speed.cloudflare.com/__down?bytes=10000000"
python3 main.py "https://speed.cloudflare.com/__down?bytes=25000000"
```

### 2. Параметры командной строки

```bash
python3 main.py --help
```

| Параметр | Короткий флаг | Описание | По умолчанию |
| :--- | :--- | :--- | :--- |
| `url` | `-u`, `--url` | Адрес ресурса для скачивания (http:// или https://) | `https://speed.cloudflare.com/__down?bytes=10000000` |
| `--count` | `-c` | Количество последовательных запросов | `10` |
| `--timeout` | `-t` | Таймаут одного запроса в секундах | `30.0` |

Пример запуска 5 запросов с таймаутом 15 секунд:
```bash
python3 main.py "https://speed.cloudflare.com/__down?bytes=10000000" -c 5 -t 15
```

## Установка зависимостей и инструментов разработки

Для запуска самого скрипта сторонние зависимости не требуются.

Для запуска тестов (`pytest`) и линтера (`ruff`) установите зависимости для разработки:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements-dev.txt
```

---

## Тестирование и линтинг

Тесты разделены по пирамиде тестирования на 3 уровня с использованием фикстур `pytest`:
1. **Unit-тесты** (`tests/unit/`):
   * `test_calculator.py` — проверка математической корректности расчета средней скорости, обработки пустых и ошибочных наборов данных.
   * `test_service.py` — проверка поведения координатора `SpeedTester` с изолированными моками интерфейсов `DownloaderInterface` и `ReporterInterface`.
2. **Интеграционные тесты** (`tests/integration/`):
   * `test_downloader.py` — запуск фикстуры локального HTTP-сервера и валидация стриминга байт компонентом `HttpDownloader`, обработки кодов 200, 404, 500 и обрыва соединения.
3. **E2E-тесты** (`tests/e2e/`):
   * `test_cli.py` — сквозной запуск `main.py` через subprocess против локального HTTP-сервера с проверкой кодов возврата, флагов командной строки и структуры отчета.

### Запуск тестов (pytest):
```bash
pytest -v
```

### Проверка линтером (ruff):
```bash
ruff check .
```

Для автоматического исправления форматирования и сортировки импортов:
```bash
ruff check . --fix
ruff format .
```
